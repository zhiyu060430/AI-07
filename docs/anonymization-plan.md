# 匿名化与脱敏实施计划

## 适用范围

本计划适用于进入 `DATASET_ROOT`、Label Studio 或版本归档的真实图片、视频、点云、标注和元数据。当前 `firephantom.versioning.desensitize` 只清理版本元数据中的常见直接标识符，不能替代图像像素脱敏。

## 入库前流程

1. 登记来源、许可证、获取时间、用途、责任人和哈希；许可证无法核验的数据拒绝入库。
2. 删除或哈希姓名、邮箱、手机号、身份证号、地址、设备序列号和自由文本中的直接标识符。
3. 对图片和视频运行人脸、车牌、屏幕文字、EXIF/GPS 和水印检测；命中时遮挡、裁剪或拒绝入库。
4. 对点云删除可识别的人体、车辆和位置标识；对标注检查自由文本。
5. 按批次抽取不少于 10% 样本人工复核，记录抽样种子、规则版本、复核人、命中数和处置结果。
6. 通过复核后才写入 DVC/版本库，并把处理工具版本和报告写入版本元数据。

## 技术边界

生产环境应使用受控的图像脱敏工具和人工抽查；本仓库提供的元数据清理、Fernet 静态加密和版本审计只能作为配套控制。不得以“已调用 `desensitize`”单独声明真实图像已匿名化。
