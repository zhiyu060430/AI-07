# 用本机作为团队共享服务器

适用于暂未部署云服务器、成员不在同一局域网的演示和协作。你的电脑运行整套Docker平台；其他成员只需浏览器和各自的平台账户。

## 开始、查看和停止分享

先启动本机平台并创建管理员，然后在源码根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/share-platform.ps1
```

首次会构建支持私有登录的API和网页，然后启用Cloudflare官方Quick Tunnel。只有隧道实际连接就绪后才输出HTTPS链接；不需要Cloudflare账户、域名、路由器入站端口映射或成员安装Docker。链接本身不是登录凭据，打开后必须用平台账户登录。

```powershell
# 查看当前可用链接
powershell -ExecutionPolicy Bypass -File scripts/share-platform.ps1 -Operation Status
# 停止远程访问；本机平台、账户和数据保留
powershell -ExecutionPolicy Bypass -File scripts/share-platform.ps1 -Operation Stop
```

需要更新分享模式的API/网页代码时追加 `-Prepare`。有正在运行或排队的生成任务时，脚本会要求先完成或取消任务，再更新入口，避免中断作业。

## 用户、角色与数据

管理员在左侧“项目成员”中创建成员账户、设置初始密码并分配角色；也可从“工程与验收”的第一项箭头跳转。成员访问你分享的HTTPS链接，登录后在权限范围内操作同一套项目数据。

网页首次自动打开登录窗口；退出后清空页面中的账户数据。分享模式下，项目、样本、图像、任务、审计记录、接口文档和监控接口均要求有效登录。后续公开注册关闭。开始分享前必须已经有管理员，避免首次初始化入口暴露在外。

上传、生成、标注、版本与账户仍保存在你电脑的Docker卷中；这不是将数据库迁移到Cloudflare。第三方隧道服务负责HTTPS网络转发。不要向成员分享数据库密码、Label Studio服务令牌或Worker密钥。

## Worker和API无需另行公开

```text
成员浏览器
  → 一个HTTPS分享链接
  → Docker中的platform-web（网页和同源/api代理）
  → platform-api:8090
  → Worker领取任务、执行FDS/Blender/GPU并更新进度
  → 同一套PostgreSQL和文件卷
```

网页自动调用分享链接下的 `/api/...`，无需让成员填写8092端口或API Key。Worker继续连接 `http://platform-api:8090`，服务密钥仍在Docker内部。数据库没有公开端口；Docker socket不挂载、不公开。

完整Label Studio后台的8082入口仍仅供本机管理；远程成员使用主平台内的审核和标注功能，后台同步由API容器完成，无需单独连接Label Studio。

## 在线要求及临时链接边界

- 你的电脑需要开机、保持联网和唤醒，Docker以及主平台/Worker/隧道容器保持运行。关闭浏览器不影响后台；电脑睡眠、关机、关闭Docker或停止隧道会使链接不可用。
- Quick Tunnel面向临时测试，没有持续可用性保证。重建隧道后域名会变化，需要重新查看并分享；链接不会保存进GitHub源码。
- Cloudflare隧道需要出站UDP或TCP 7844。自动模式会根据网络选择QUIC或HTTP/2；只有拿到地址但隧道未连通时，脚本不会将其作为可用链接交付。它不需要打开你电脑的入站7844端口。
- 后续需要长期固定网址时，使用有账户/域名的固定隧道或迁移云服务器；成员仍通过同一入口和同一套账户访问。

参考：[Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)、[出站网络要求](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-with-firewall/)。
