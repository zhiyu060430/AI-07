# 用户手册

打开 `http://127.0.0.1:8765/` 使用 React 工作台；移动端和桌面端共用同一 API。Swagger UI 位于 `/docs`。第一次打开时创建管理员账号，之后用邮箱和密码登录。管理员在侧栏添加其他账号。没有公开注册、邮箱验证或密码找回。侧栏的「Label Studio」使用当前工作台账号进入，页面上不会再出现 Label Studio 登录框。

页面地址用 `#/scenes`、`#/scenes/<id>`、`#/library`、`#/jobs/<id>`、`#/datasets` 这样的 hash 路由，刷新和分享链接都会回到同一页。顶栏的「当前数据集」决定送审和发布用哪个数据集，所有页面共用。

1. **场景库**。新建场景是两步：先选一张带预览图的预设（房间火灾、林区火灾、工业区火灾），名称会填成「预设 + 当天日期」，再点「创建并打开」。房间默认是沙发、木桌和盆栽。林区默认是松树、灌木、草、树桩和倒木围着地面的火，没有树冠那块板，也没有燃料床，雨能落到地面。工业区默认是油桶、木箱、塑料箱和液化气罐围着油池，罐体和管架仍是不燃烧的方块。已经保存的场景保持原来的摆放，只有重新套用预设或点「恢复默认摆放」才会换成这一套。卡片上可以重命名、复制和删除；删除只把场景移出场景库，已经生成的样本和作业记录不受影响。
2. **工作台**（点开一个场景）。同一页分三栏：三维视口、摆放面板、生成面板，不再来回跳转。
   - 摆放：右侧上方滚动场景、放入和大纲，属性钉在下面。大纲按灯光、摄像机、求解、物体、结构分组。点空白处取消选择。结构里的墙、天花板、罐体这些方块可以移动、缩放、改名、改角色和删除，也可以再加一块。地板是地面，跟着场地的长宽走，不是方块。天花板默认只有选中才画出来，点它的眼睛可以一直显示。火柱会在显示和烘焙里挖开实体，手柄拖的是完整方块。视口下方的模型架可以搜索和按分组挑模型，拖进视口会跟着落点，松开就放下；单击是自动找空位。场景里最多 8 件。「上传 glb」打开模型库。单击物体只是选中，在属性里改数字，或用手柄和方向键移动。双击摄像机、属性里的「进入视角」，或工具条上的相机图标，才进入该机位。
   - 模型库（`#/library`）：内置模型和「我的上传」分开。内置的不能删。可以一次选很多 `.glb`，或拖进来，或上传一个里面装着 `.glb` 的 zip（其他文件会跳过）。一次最多 200 个，每个仍是 8 MB、5 万面以内。某个文件不合格会写明原因，已经通过的仍然留下。短边不到 0.45 米、但不是零厚度的模型会按比例放大到最短边 0.45 米再摆进去。删掉一个上传之后，已经用过它的场景仍画出燃料盒。石头也按燃料盒燃烧，燃料可以改。
   - 灯光：大纲里可以加点光、太阳、聚光和面光，最多 8 盏。没改过时是自动补光和太阳，标着「自动」；一改、一加或一删，就收成这个场景自己的灯，烘焙不再另加天气太阳。把灯全部删掉会留下空列表，表示一盏都不要。点光、聚光和面光按瓦数，不跟天气变。太阳填的是晴天强度：雨关掉，雪大约两成。视口另有一层很弱的环境光，只为看清墙，不进烘焙。
   - 点燃：勾选「一开始就烧」后，从靠近火的一侧逐段点着，不是整件一起着。没勾则等火烧过来，远的一侧时间不够就先不着。
   - 气体域是烘焙用的盒子，可以改中心、边长和分辨率，也可以「铺满场景」。选中气体域后，面板里还能调预热时长、噪声细节、火焰外观和渲染采样。预热只让雨雪落到画面里、求解器稳住。火从第一张图才点着，烟是烧掉的燃料产生的，不会在第一帧铺满。面板顶部显示预计烘焙时间，超过 30 分钟的设置提交时会被拒绝。没改过的相机和气体域会跟着火源重算，「恢复自动」回到这个算法。「恢复默认摆放」只恢复家具，不动结构、场地和灯。场地每边可以改成 1 到 80 米。套用预设会换成那一套结构、场地和默认摆放，并清掉起火点、摄像机、气体域和自定义灯光。烟羽系数仍跟着预设，不跟着方块改。
   - 保存：标题旁显示「未保存」或「第 N 版」。⌘S 或保存按钮会存成新版本并更新缩略图。只改名不算新版本。离开前有未保存改动，浏览器会提醒。
   - 生成：选风速、温度、湿度，再选天气、视角和每个视角的帧数。晴、雨、雪都可以选。天空跟着顶盖：不燃烧的方块顶到场地高度，并盖住雨雪落下的范围时，这一烘是室内光，雨雪落在顶上，地面保持干燥；留出缺口或删掉顶盖就是室外光，雨雪进到场地里。火焰仍跟着所选天气，雨更凉、烟更多，雪稍凉。每种天气单独烘焙一次，各视角都从这次烘焙渲染，每一帧是一个样本。增强（噪声、模糊、光照变化）另存派生样本，不替换原图。高级里有种子、最小火焰占比和重复烘焙次数。Stable Diffusion 背景重绘在数据集页的「SD 增强」里，只对已审核样本做。有未保存的摆放时，提交前会先保存。参数可以存成生成预设，生成预设不含摆放。
   - 结果：生成面板下方列出这个场景最近的几次生成。点一组打开右侧抽屉：大图上叠加火焰掩码和框，旁边是这一组的视频，下面是全部帧。被筛除的帧写明原因（火焰太小、过暗、过曝）；火焰被画面边缘截断只提示，不筛除。勾选帧后「送审」，或在组合列表上「全部送审」。「只重跑这一组」用这次作业当时的参数重新渲染这一组；烘焙有缓存，不会重新烘焙。
3. **作业**。左边是全部作业，右边是同样的组合网格和抽屉。作业关联了场景时可以「打开场景」；旧作业没有场景时可以「摆放存为场景」。运行中的作业可以取消，当前这一组完成后停止。
4. **数据集与版本**。先选或新建数据集。上方显示可送审、审核中、已审核、已拒绝的数量。页面每 30 秒、以及窗口回到前台时会同步 Label Studio：已提交的标注回写成「已审核」，跳过的任务记为「已拒绝」，审核里改的框、关键点和属性都会保留。已经发布的样本不再改动。
   - 发布：按钮旁写明这次会新增和移除多少样本。每个版本包含数据集里全部已审核样本，并记录父版本；同一段序列的帧固定在同一个 train/val/test 划分。版本里有 `data.yaml`、`images/<split>`、`labels/<split>`、每个划分的 COCO 和 VOC，可以直接给 `python -m firephantom.annotation.train` 用。类别编号固定为 flame=0、smoke=1、ember=2。
   - 版本：「设为当前版本」就是回滚，下次发布以它为基础，之后版本新增的样本不会自动带上。勾两个版本对比数据量、天气比例、标注错误率，以及新增、移除和换了划分的样本。
5. 顶栏显示 `/api/v1/system/status` 返回的可用内存。Apple Silicon 机器低于内存阈值时，作业在下一组开始前停下并写明原因；Tiny-SD 也会拒绝冷启动。停止其他 MPS 任务后再重跑即可。

FID 和 IS 在发布时对整个版本计算：FID 需要配置 `FIRE_REFERENCE_DATASET`，越低越好；IS 越高越好。外部工具不可用时，作业里写明退回了哪种后端，物理场投影仍可生成带掩码的样本。
