# 答辩演示提纲

这是可直接转成答辩 PPT 的 10 页提纲，演示数据应使用实际生成的版本 ID 和验收报告中的结果。

1. **问题与目标**：真实火焰采集的安全、成本和覆盖范围限制，以及 SE2026-AI-07 的目标。
2. **系统边界**：Blender 物理仿真、生成式合成、标注、质量筛选和 DVC；不接入消防采集设备。
3. **总体架构**：FastAPI 工作台、物理引擎、Stable Diffusion、Label Studio、指标和 DatasetStore。
4. **物理建模**：房间、林区、工业区三种几何，风速/温度/湿度/燃料参数，温度/烟雾/流场输出。
5. **多模态合成**：Blender 一次烘焙，按环境、天气、视角渲染火焰视频；Stable Diffusion 对每个组合做 img2img。点云来自参数化温度场。
6. **标注与导出**：边界框、类别、关键点、多标签属性，Label Studio prediction，以及 COCO/VOC/YOLO。
7. **质量与可复现**：FID、IS、SSIM、质量阈值、固定 seed、模型 profile 和请求指纹。
8. **版本与安全**：DVC 本地缓存、增量/冲突/回滚、Fernet 静态加密、脱敏、HTTPS/CORS 配置。
9. **现场演示**：提交任务、查看 `tool_runs`、下载 archive、回滚版本、查询批处理作业。
10. **验收与限制**：展示测试覆盖率和真实环境待测的物理误差、FID、标注准确率、mAP 及性能指标。
